How it works

Three steps. No setup.

  1. Add your PDFs

    Drop one file or hundreds. Flipkart, Meesho, Amazon and Shiprocket are recognised automatically.

  2. We trim the label

    Only the shipping label is kept. Invoices and blank margins are cut away.

  3. Print and ship

    Get an A4 sheet with cut marks, a thermal 3x5 / 4x6 PDF, or PNG images.

    About TrimLabel

    Version 1.0.0 (Web Studio Edition)

    TrimLabel — E-Commerce Label Manager

    TrimLabel is a professional web application built for Flipkart, Meesho, Amazon, Shiprocket, and custom marketplace shipping label automation.

    Features 100% offline client-side vector PDF cropping, HTML5 interactive crop template learning, smart marketplace detection, and instant A4 grid sheet assembly. Zero installation required.

    Need a new label layout?

    Using a courier or marketplace we don't support yet, or have a custom label format? Email a sample PDF (remove any customer details first) to swill8580@gmail.com and we'll try to add it.
