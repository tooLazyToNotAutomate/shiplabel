**ShipLabel Studio** is a high-performance, vector-based shipping label management tool designed for e-commerce sellers, fulfillment centers, and online merchants. It automates the cropping, formatting, and batch-printing of PDF shipping labels generated by major marketplaces such as **Flipkart**, **Meesho**, **Amazon**, **Shiprocket**, and custom platforms.

ShipLabel Studio features **dual runtime support**: run it as a lightweight **Desktop GUI Application** (Python/CustomTkinter) or directly inside your web browser as a **100% Client-Side Web Studio** with zero setup or server overhead.

---

## Why ShipLabel Studio?

Managing shipping labels from multiple e-commerce platforms often involves tedious manual cropping, awkward PDF layouts, and wasted paper. Existing online converters often require uploading customer address data to third-party servers, posing privacy and data security risks.

**ShipLabel Studio solves this completely:**
- 🛡️ **100% Private & Offline**: All processing happens locally on your computer or in browser memory. No data ever leaves your device.
- ⚡ **Lossless Vector Quality**: Unlike raster croppers that blur barcodes, ShipLabel edits PDF crop/media boxes directly, retaining crisp 300+ DPI barcodes for 100% scanner readable labels.
- 💰 **Paper & Cost Savings**: Automatically tile up to 6 shipping labels per page onto standard A4 paper with cut marks, allowing small sellers to print efficiently using standard office printers.
- 🚀 **Lightning Fast**: Batch process hundreds of shipping labels in seconds using multithreaded (Desktop) or asynchronous memory (Web) pipelines.

## Features at a Glance

| Feature | Description |
| :--- | :--- |
| **Vector PDF Cropping** | Pure vector manipulation with PyMuPDF / pdf-lib — zero quality loss or pixelation. |
| **Dual Interface** | Modern native Desktop App (CustomTkinter) + zero-install Web Studio (HTML5/JS), sharing one navy & blue design system. |
| **Marketplace Presets** | Built-in templates for Flipkart (3x5), Meesho (Top-half), Amazon (A6/Top-half), and Shiprocket. |
| **Interactive Crop Template Editor** | Draw custom crop boxes visually over sample PDFs to learn custom label formats. |
| **Smart Auto-Detection** | Automatically matches uploaded PDFs to the correct marketplace template based on dimensions and text hints. |
| **Multi-Layout Output Engine** | Export to Thermal Printers (3x5", 4x6"), A4 Grid Sheets (4-up, 2-up, 6-up), or PNG ZIP archives. |
| **Cut Mark Generation** | Automatically adds light gray corner ticks around grid cells for accurate manual or guillotine cutting. |
| **Bulk ZIP & Directory Scan** | Upload single PDFs, multi-page PDFs, entire directories, or ZIP files in batch mode. |
| **Template Import / Export** | Share custom label templates across team members via JSON configuration files. |

## Architecture & Technology Stack

```
ShipLabel Studio

 │    ├── main_window.py      -> Responsive sidebar layout container

      └── web/js/crop_canvas.js   -> Interactive HTML5 Canvas crop box editor

      └── android/                -> Mobile UI + native shell (see android/README.md)
```

## How It Helps People (Use Cases)

### 1. E-Commerce Sellers & Warehouse Operators
Sellers handling dozens or hundreds of daily orders on Flipkart, Meesho, and Amazon spend hours opening individual PDFs and cropping labels. **ShipLabel Studio automates this into a 1-click batch workflow.**

### 2. Budget-Conscious Small Businesses
Small sellers who haven't invested in expensive thermal roll printers can arrange **4-Up or 6-Up grid sheets on A4 adhesive paper**, reducing label paper costs by up to 75%.

### 3. Logistics & Courier Scan Reliability
Scanners at courier hubs frequently reject labels cropped via screenshot tools or raster image converters due to blurry barcodes. ShipLabel retains native PDF vector paths, ensuring **100% barcode scan rates**.

### 4. Strict Privacy & Data Compliance
Customer addresses and phone numbers are sensitive PII (Personally Identifiable Information). ShipLabel operates **completely offline**—giving privacy-minded businesses complete peace of mind.

## Quick Start Guide

### Option A: Web Studio (Browser — Zero Installation)

1. Launch the built-in local server:
   ```bash
   python web/server.py
   ```
2. Open your web browser at `http://localhost:8000`.
3. Drag & drop your shipping PDFs, select your template or let Smart Auto-Detect handle it, and click **Process & Download**.

### Option B: Desktop Application (Python GUI)

#### Prerequisites
- Python 3.9 or higher

#### Installation
1. Clone or download this repository:
   ```bash
   git clone https://github.com/Mohd-afk/shiplabel.git
   cd shiplabel
   ```
2. Install Python dependencies:
   ```bash
   pip install -r desktop/requirements.txt
   ```
3. Run the desktop application:
   ```bash
   cd desktop
   python main.py
   ```

## How to Use

### 1. Processing Shipping Labels
1. Go to the **Process Labels** tab.
2. Import one or more shipping label PDF files.
3. Choose a marketplace template (e.g. *Flipkart 3x5 Thermal* or *Meesho Thermal*).
4. Choose your output mode:
   - **Thermal 3x5 / 4x6**: Formats 1 label per page, scaled for thermal label printers.
   - **A4 Sheet (4-Up Grid)**: Arranges 4 cropped labels per A4 page with optional cut marks.
   - **A4 Sheet (6-Up Grid)**: Arranges 6 cropped labels per A4 page.
   - **PNG ZIP Archive**: Converts labels into individual high-res image files.
5. Click **Process & Download**.

### 2. Learning Custom Templates
1. Go to **Template Manager** and click **Create New Template**.
2. Upload a sample shipping label PDF.
3. Drag your mouse over the preview canvas to highlight the label area, or click one of the quick presets (*Preset Flipkart 3x5*, *Top Half*, etc.).
4. Enter a template name and marketplace, then click **Save Crop Template**.

### 3. Batch Processing
1. Navigate to **Batch Processor**.
2. Drop dozens of PDF files or a ZIP archive containing invoices.
3. Select your template and output grid format.
4. Click **Start Batch Processing** to format all files concurrently.

## Design System

Both interfaces (the Web Studio in `styles.css` and the Desktop GUI in `ui/theme.py`) share the same navy & blue palette.

| Token | Hex | Used for |
| :--- | :--- | :--- |
| Navy Blue | `#1B1B39` | Sidebar, hero banner, primary text |
| Primary Blue | `#3965FA` | Buttons, active nav item, focus rings, crop box |
| Soft Blue | `#99B7FC` | Dashed drop-zone border, hover borders, sidebar labels |
| Pale Blue | `#E9EBFF` | Hover fills, badges, icon tiles |
| Base White | `#FFFFFF` | Cards, inputs |
| Light Gray | `#EDEDED` | Canvas backdrop, progress track |
| Dark Gray | `#202020` | Reserved for high-contrast text and dark surfaces |

**UI rules**

1. No neon or glow effects, neon gradients, or dark glassmorphism. Shadows stay soft and neutral.
2. Text keeps WCAG AA contrast on white and pale-blue backgrounds.
3. Layouts are responsive: dashboard widgets reflow from 1 column on mobile to multiple columns on desktop. On phones the sidebar becomes an off-canvas drawer, and primary actions stay above the system navigation bar.
4. Every interactive button and input has a descriptive `id` for automated testing.
5. Icons are a single consistent stroke-icon set (inline SVG sprite in `index.html`), not emoji.
6. Motion is subtle (fade/rise on views, hover lift on cards) and disabled under `prefers-reduced-motion`.

## Directory Structure

```
LABELPDF/
├── web/                   # Web Studio (deployed to Vercel)
│   ├── index.html
│   ├── styles.css
│   ├── js/                # app.js, crop_canvas.js (web UI only)
│   └── server.py          # Local dev server (also serves ../shared)
├── android/               # Android app (Capacitor), see android/README.md
│   ├── src/               # ui/, components/, pages/, js/ (mobile UI)
│   └── native/            # Generated Android Studio project
├── desktop/               # Python desktop app
│   ├── core/              # PDF / batch / output / template engine
│   ├── ui/                # CustomTkinter views & widgets
│   └── tests/  data/  main.py  requirements.txt
├── shared/                # JS engine used by web AND android
│   ├── js/                # pdf_engine.js, template_manager.js, security.js
│   └── vendor/            # pdf-lib, pdf.js, JSZip (self-hosted)
├── scripts/build.js       # Combines web/ or android/src with shared/
├── vercel.json            # Builds web/ + shared/ into dist/web
└── package.json
```

Run from the right folder: `python web/server.py` (web), `cd desktop && python main.py` (desktop), `cd android && npm run apk` (Android).
